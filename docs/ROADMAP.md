# ATLAS Roadmap

## Phase 0 — Foundation
Monorepo, CI, environments, auth, organizations, database/migrations, design system, observability, feature flags, audit primitives, secret strategy.

## Phase 1 — Canonical Company + Raise
Founder onboarding, company truth model, deck extraction with confirmation, raise constraints, founder priorities, dilution/scenario calculator.

## Phase 2 — Investor Intelligence Graph
Investor/fund/person schema, source/claim provenance, ingestion workers, entity resolution, admin corrections, freshness engine, search.

## Phase 3 — Match Engine + Capital Router
Eligibility, feature scoring, confidence, evidence explanations, regional/archetype routing, round coverage, saved targets, recomputation/versioning, evaluation harness.

**V1 proof checkpoint:** ATLAS consistently surfaces high-fit global investors that expert/manual search would plausibly miss.

## Phase 4 — Fundraising Execution
CRM, contacts, sequences, human-approved AI outreach, email/calendar adapters, meeting briefs, follow-up intelligence, analytics.

## Phase 5 — Diligence
Data rooms, ACLs, signed access, request lists, authorized document Q&A, audit logs, document extraction.

## Phase 6 — Deal Intelligence
Offer ingestion, term normalization/confirmation, dilution/control analysis, strategic-value assumptions, side-by-side comparison, closing checklist.

## Phase 7 — Investor Product
Verified investor profiles, mandate management, AI-ranked deal flow, saved theses, team pipeline, controlled company contact/request workflows.

## Phase 8 — Marketplace
Verified participants, structured inbound interest, founder-controlled visibility, competitive offer workflows, ranking integrity controls.

## Phase 9 — Transaction Infrastructure
Only after legal/provider/security readiness: eligible transaction workflows, settlement adapters, identity/eligibility credentials, ownership attestations, stablecoin rails where lawful, compliant transfer controls.

## Phase 10 — Private-Market Network
APIs, institutional integrations, advanced proprietary outcome models, portfolio/company lifecycle, secondary/private liquidity only where properly structured.

## Build Priority Rule
Do not build Phase 9 because it is exciting while Phase 3 is unproven. ATLAS earns the right to become capital infrastructure by first becoming exceptionally good at capital routing.
