## Design Direction

ATLAS should feel like institutional financial software redesigned for modern founders: dense when useful, visually calm, premium, globally oriented, and explainable. Avoid generic AI-gradient dashboard aesthetics. Desktop is primary for deep raise work; mobile supports monitoring, approvals, meetings, and follow-ups.
